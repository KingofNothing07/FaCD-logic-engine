# FaCD Solutions Library

A curated collection of real-world problems worked with FaCD (Factored Context and Discernment). Each entry shows a claim, plan, or question written as `Left = Right`, the factors and tags that resolved it, and a clear Clarity outcome.

This library starts empty. Entries are added by pull request. The maintainer reviews every submission and decides what stays, what is edited, and what is removed so the library remains useful and accurate.

## How to contribute

1. Fork the repo (or open a PR directly if you have access).
2. Add a new entry below using the template.
3. Open a pull request with a short description of the problem and why the FaCD pass is useful to others.
4. The maintainer will review, approve, revise, or close the PR.

You do not need to be an expert. Clear, honest walkthroughs of everyday decisions, technical claims, or strategy questions are welcome.

## Entry template

Copy and fill this block for each new solution:

```markdown
### [Short title]
**Problem:** One-sentence description of the claim, plan, or question.
**Domain:** (e.g. trading, product design, personal decision, technical architecture)
**FaCD outcome:** (tag such as True / False / Unsolved / Unknown + one-sentence Clarity)
**Key factors or bridges:** (brief list of the decisive openings or joins)
**Notes:** (optional context, what was learned, or follow-up)
**Contributor:** (GitHub username)
**Date:** YYYY-MM-DD
```
