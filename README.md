# FaCD — Factored Context and Discernment

Algebraic test of semantics. Write claims, plans, or options as `Left = Right`, factor both sides in public, tag the result, and make the reasoning rerunnable. Standalone or companion to Semantic Shorthand.

## Install
1. Open the skill package below.
2. Copy the entire file.
3. Paste into your AI as a system prompt, custom instructions, project knowledge, or skill file.
