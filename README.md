# FaCD — Factored Context and Discernment

**Algebraic test of semantics.** Write a claim, plan, option set, testimony, or staged goal as `Left = Right`. Factor both sides in public, open only the gates that do work, tag the result, and leave a page that a later reader can rerun.

Standalone or companion to [Semantic Shorthand](https://github.com/KingofNothing07/Semantic-Shorthand). They share the same Language Core notation: a finished FaCD pass is already valid shorthand, and a `=` inside a shorthand log is already a FaCD-testable claim. FaCD tests and discerns; Semantic Shorthand logs and inherits.

## Why try it
- Make reasoning checkable instead of relying on mood or summary.
- Test claims against records, stacked options against constraints, missing transforms, or staged goals.
- Produce a tagged result (True / False / Unsolved / Unknown) with a clear Clarity sentence.
- Leave a transparent page: raw set, equation, factors, bridges, working, tag, and outcome — anyone can re-run it.
- Useful for technical decisions, strategy, testimony vs. evidence, synthesis from hits and misses, and any work that must remain honest and reconstructible.

## Install (30 seconds)
1. Open the skill package below.
2. Copy the **entire** file.
3. Paste it into your AI as a system prompt, custom instructions, project knowledge, or skill upload.

The package teaches the Language Core completely enough to run standalone. Notation lives in fences — use plain text or fenced Markdown and disable autocorrect for safety.

## How it works (brief)
Write the demand as the Right side. Factor both sides. Apply only useful gates. Tag the result. Lead Clarity with the solution. Synthesis (when needed) keeps the same Right and builds a new Left from supporting factors — including misses — then reruns.
